# Radioecological & Evolutionary Impacts of Nuclear Disasters: Chernobyl vs. Fukushima

An interactive, modern, minimalist web platform synthesizing comparative radioecological research on the biological consequences, evolutionary mechanisms, and statistical methodologies surrounding ionizing radiation impacts on wildlife in Chernobyl and Fukushima.

Based on the research and reviews of **Møller & Mousseau**, synthesized by **Shadman Shakib** (Department of Biotechnology, BRAC University)[cite: 1].

---

## 📌 Features

- **Large Minimalist Hero Section**: Features paper highlights, reviewer metadata, and a direct link to the full review PDF.
- **Core Synthesis Highlights**: Quick cards detailing acute radiotoxicity, physiological biomarkers, and evolutionary adaptation critiques.
- **Comparative Analysis Matrix**: Direct comparison between Chernobyl (1986) and Fukushima (2011) across exposure timeframes, statistical models (Welch ANOVA), and species abundance[cite: 1].
- **Interactive Biomarker Simulator**: Visualizer showcasing the physiological cascade on *Hirundo rustica* (Barn Swallow)[cite: 1].
- **Methodological Critique**: Overview of sampling bias, pseudoreplication, and the gold-standard Reciprocal Transplant design.

## 📄 Source Review & References

This website synthesizes the following foundational literature reviewed by Shadman Shakib[cite: 1]:

1. **Møller, A. P., & Mousseau, T. A. (2006).** *Biological consequences of Chernobyl: 20 years on.* Trends in Ecology & Evolution, 21(4), 200-207.[cite: 1]
2. **Møller, A. P., Nishiumi, I., Suzuki, H., Ueda, K., & Mousseau, T. A. (2013).** *Differences in effects of radiation on abundance of animals in Fukushima and Chernobyl.* Ecological Indicators, 24, 75-81.
3. **Møller, A. P., & Mousseau, T. A. (2016).** *Are organisms adapting to ionizing radiation at Chernobyl?* Trends in Ecology & Evolution, 31(4), 281-289.

## 🚀 Quick Start / Local Deployment

No heavy build tools or framework installations are needed. The platform is built using pure single-file HTML5, Tailwind CSS, and lightweight JS.

### Option 1: Open Directly
1. Clone or download this repository.
2. Open `index.html` in any modern web browser.

### Option 2: Run via Python Local Server
```bash
# Clone the repository
git clone [https://github.com/shadmanshakiblxl/chernobyl-fukushima-comparative-study.git](https://github.com/shadmanshakiblxl/chernobyl-fukushima-comparative-study.git)

# Navigate into the project folder
cd YOUR-REPO-NAME

# Start a local HTTP server
python -m http.server 8000
